# EduApp

Одностраничный сервис для подбора образовательных материалов по Википедии.
Пользователь вводит тему — EduApp показывает до 12 карточек статей со ссылкой на полный текст.

Проект по курсу «Цифровые медиа». Авторы: Мишненков Артём, Викторов Пётр, группа 2-МД-13.

## Возможности
- поиск по русской Википедии;
- карточки с очищенным фрагментом и кнопкой «Читать статью в Википедии»;
- тип карточки (статья / список / упоминание) и метка «Основная статья»;
- фильтр по типу со счётчиком;
- избранное (хранится в браузере);
- адаптивная вёрстка для ПК и телефонов.

## Структура
```
index.html          разметка: header, nav, main, footer
css/style.css       стили
js/script.js        поиск, очистка фрагментов, фильтры, избранное
data/data.json      настройки: лимит карточек, примеры тем, шаблоны очистки
assets/images/      logo.svg (логотип), hero.svg (главная), empty.svg, favorites.svg (заглушки)
.nojekyll           нужен для GitHub Pages
```

## Запуск
Откройте `index.html` в браузере (нужен интернет). Если `data/data.json` не загрузится
при открытии файла с диска, сайт всё равно работает — без кнопок с примерами тем.
Полный вариант: `python -m http.server` или GitHub Pages.

## GitHub Pages
Settings → Pages → Branch `main`, папка `/ (root)` → Save.
Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Источник данных
[MediaWiki API](https://www.mediawiki.org/wiki/API:Main_page) — открытый, бесплатный, без ключей.
